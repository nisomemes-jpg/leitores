# A Voz da Palavra

Site de formação permanente para leitores e candidatos da Paróquia Nossa Senhora de Lourdes, em Areia Preta, Natal/RN. O conteúdo não depende de cinco encontros nem de um calendário específico: pode ser usado integralmente ou por temas, sempre que a comunidade precisar.

## Onde editar

- app/page.tsx: conteúdo, roteiros permanentes, locais de serviço e referências.
- app/globals.css: cores, tipografia, espaçamento e responsividade.
- app/layout.tsx: título, descrição e compartilhamento.
- public/og.png: imagem principal e cartão social.

As listas editáveis ficam no início de app/page.tsx.

Para executar: npm install e npm run dev.
Para validar: npm run build.
Para gerar os arquivos prontos do GitHub Pages: npm run export:github.

Antes do uso oficial, revisar com o pároco e a Pastoral Litúrgica especialmente vestes, eventual rito de envio e costumes paroquiais.
